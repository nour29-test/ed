# نظام إدارة المعلم الذكي (Smart Teacher App) 📱

تطبيق موبايل متكامل للمعلمين والمراكز التعليمية، تم بناؤه باستخدام **Flutter** ونظام تخزين محلي **SQLite** دون الحاجة لخوادم سحابية، لضمان العمل دون اتصال بالإنترنت في أي وقت وأي مكان.

---

## ✨ المميزات الرئيسية

1. **إدارة الحصة اليومية**:
   - رصد سريع للحضور والانصراف (حاضر، غائب، متأخر) بنقرة واحدة.
   - متابعة حل الواجب المدرسي (تم الحل، حل جزئي، لم يحل).
   - رصد درجات التسميع الشفهي والكويز والامتحان الشهري مع أزرار الزيادة والنقصان السريعة (+ / -).
   - تدوين الملاحظات الفردية لكل طالب في الحصة.
   - زر تنبيه ومتابعة فورية لولي الأمر عبر واتساب.

2. **إدارة الطلاب والمجموعات**:
   - تقسيم دراسي هرمي (المراحل الدراسية ← المجموعات ومواعيدها ← الطلاب).
   - تسجيل فوري وسهل لبيانات الطالب وولي الأمر.
   - بحث فوري بالاسم وفرز أبجدي.

3. **المصروفات والرسوم الشهرية**:
   - متابعة سداد اشتراكات الشهر بنظام السويتش (Switch) السريع.
   - كارت إحصائي ديناميكي يوضح إجمالي المحصل والمتأخرات وعدد الطلاب المسددين.
   - تسجيل تاريخ السداد تلقائياً.

4. **التقارير الشهرية ومراسلة WhatsApp**:
   - توليد تقرير شهري تراكمي دقيق ومنسق وجاهز للإرسال.
   - إرسال التقرير بضغطة زر واحدة عبر تطبيق WhatsApp الرسمي لولي الأمر مباشرة.

5. **النسخ الاحتياطي والأمان**:
   - تصدير واسترجاع نسخة احتياطية كاملة (JSON Backup) لحماية البيانات ونقلها لأي هاتف بديل.
   - حفظ ملف تعريف المعلم لإدراجه تلقائياً كتوقيع على التقارير.
   - دعم كامل للوضعين الفاتح والداكن (Light & Dark Mode) بخط **Cairo** العربي.

## 🚀 تشغيل وبناء التطبيق

### 1. المتطلبات
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install) (الإصدار 3.16 فما فوق).
- Android Studio أو VS Code مع إضافات Flutter/Dart.

### 2. تثبيت الحزم (Dependencies)
```bash
cd app_edu_flutter
flutter pub get
```

### 3. تشغيل التطبيق في وضع التطوير
```bash
flutter run
```

### 4. بناء ملف التثبيت لأجهزة أندرويد (Release APK)
```bash
flutter build apk --release
```
ستجد الملف الناتج في المسار:
`build/app/outputs/flutter-apk/app-release.apk`
